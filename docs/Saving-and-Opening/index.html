Saving and Opening

About

The ⋯ menu at the top right of every tab saves what you have entered under a name, opens a saved set again, and resets the inputs to their defaults. A set can be kept in the app or written to a file that stays when the app is gone.

Sets kept in the app live inside it, so deleting the app deletes them. To keep a case safe, also save it to a file. You choose where the file goes, such as iCloud Drive or On My iPhone on an iPhone, or Downloads or Google Drive on an Android phone, and it stays there when the app is gone.

The ⋯ menu

Tap ⋯ beside Docs ↗. The menu is headed with the calculation it acts on: the tab's name on Property and Units, or the mode or case you have open on Thermo and Case. It holds:

  • Recent: your three newest saved sets for this calculation, each with the date it was saved. Tap one to open it.
  • Open a saved set…: every set saved for this calculation, and Open from a file….
  • Save…: the Save this set sheet.
  • Reset to defaults (Reset this case to defaults on Case): puts the original inputs back on screen.

Saving belongs to one calculation, so on Thermo and Case choose a mode or a case first. From the Choose a mode or All cases cards, Save… and Open a saved set… only ask you to choose a calculation.

Saving inside the app

  1. Tap ⋯, then Save….
  2. Type a Name of up to 40 characters. The field starts with the name you last saved or opened, so saving again keeps one set up to date.
  3. Leave Where on In the app and tap Save.

The set then shows up under Recent in the ⋯ menu. Saving under a name that already exists replaces that set; the button reads Replace when it will. Each calculation keeps up to 25 sets; at the limit the app refuses to save and asks you to delete one first, rather than dropping one on its own. The set you last saved or opened comes back when the app starts.

What gets saved

The What gets saved note on the sheet says it: the calculation's inputs, including any unit you changed on a single field. Results are not stored; they are calculated again when you open the set and tap Calculate. A method picked on a data-source sheet or under Methods used is not saved with the set either (see Methods and data sources).

What a set holds depends on the tab: the Property and Units tabs each save the whole tab, while Thermo and Case save the one mode or case you have open. Property also keeps its Recent names. Each tab's own page describes it.

Opening a saved set

Tap ⋯, then a set under Recent, or Open a saved set… for the full list. In the list, the set you last used is marked last used. Tap a name to open it. The icons beside each set write it to a file, rename it, or delete it; a delete asks you to confirm first.

Resetting

Reset to defaults puts the original inputs back on screen and leaves your saved sets untouched. On Thermo it resets the mode you have open and leaves the other modes as they are; on Case, Reset this case to defaults does the same for the open case. Tapped on the Choose a mode or All cases screen, it resets every mode or every case.

Saving to a file

  1. Tap ⋯, then Save…, and type a name.
  2. Set Where to Files / iCloud and tap Save. Your phone's file-saving screen opens.
  3. Choose where to keep it and confirm.

The file is a .json file named after the calculation and the set, for example ProcessChem - Reaction - Site case.json. It holds one case: the inputs of the calculation you were on. Saving to a file does not add the set to the app's own list; save it In the app as well if you want both. If you back out of the file-saving screen, the Save sheet stays open.

You can also write out a set you already saved in the app: tap Open a saved set…, then the save icon beside the set.

Opening from a file

  1. Go to the tab and calculation the file came from. On Thermo, choose the mode; on Case, choose the case.
  2. Tap ⋯, Open a saved set…, then Open from a file…, and choose the file.
  3. The form fills in with the saved values.

Opening a file fills the form on screen but does not add the set to the app's own list. Save it In the app afterwards if you want it kept there too.

A file only opens on the tab and calculation it was saved from, because its numbers belong to that form. If you are somewhere else, the app says where the file belongs and changes nothing. A file that is not a ProcessChem case, is damaged, or was made by a newer version of the app is refused with a message, and nothing on screen changes.

Units

Every number is saved together with the unit it was in. A pressure saved as 100 psi opens as the same pressure even if you have since set pressure to bar on the Units tab; it shows as 6.89 bar, not 100 bar. A field whose unit you changed on the field itself keeps that unit, so it opens as 100 psi. The same holds for a set opened from the app's own list.

Moving a case elsewhere

A saved file is an ordinary file, so you can copy it like any other: keep it in a cloud drive, send it by email or a messaging app, or put it on another device. Open it from ProcessChem there in the same way.
