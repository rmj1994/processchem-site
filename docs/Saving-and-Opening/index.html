Saving and Opening

About

Every tab has Open, Save and Reset buttons under its heading. Save keeps what you have entered under a name, and Open brings it back.

Those saved sets are kept inside the app, so deleting the app deletes them. To keep a case safe, also save it to a file. You choose where the file goes, such as iCloud Drive or On My iPhone on an iPhone, or Downloads or Google Drive on an Android phone, and it stays there when the app is gone.

Saving inside the app

Tap Save, type a name of up to 40 characters, and tap Save again. Each calculation keeps up to 25 sets, and saving under a name that already exists replaces it. The set you last saved or opened comes back when the app starts. Reset puts the original inputs back on screen and leaves your saved sets untouched.

What a set holds depends on the tab: the Property and Units tabs each save the whole tab, while Thermo and Case save the one mode or case you have selected. Each tab's own page describes it.

Saving to a file

  1. Tap Save and type a name.
  2. Tap Save to a file…. Your phone's file-saving screen opens.
  3. Choose where to keep it and confirm.

The file is named after the calculation and the set, for example ProcessChem - Reaction - Site case.json. It holds one case: the inputs of the calculation you were on. Saving to a file does not add the set to the app's own list; use Save for that as well if you want both.

You can also write out a set you already saved in the app: tap Open, then the save icon beside the set.

Opening from a file

  1. Go to the tab and calculation the file came from. On Thermo, choose the mode; on Case, choose the case.
  2. Tap Open, then Open from a file…, and choose the file.
  3. The form fills in with the saved values.

Opening a file fills the form on screen but does not add the set to the app's own list. Tap Save afterwards if you want it kept there too.

A file only opens on the tab and calculation it was saved from, because its numbers belong to that form. If you are somewhere else, the app says where the file belongs and changes nothing. A file that is not a ProcessChem case, is damaged, or was made by a newer version of the app is refused with a message, and nothing on screen changes.

Units

Every number is saved together with the unit it was typed in. A pressure saved as 100 psi opens as the same pressure even if you have since set pressure to bar; it shows as 6.89 bar, not 100 bar. The same holds for a set opened from the app's own list.

Moving a case elsewhere

A saved file is an ordinary file, so you can copy it like any other: keep it in a cloud drive, send it by email or a messaging app, or put it on another device. Open it from ProcessChem in the same way.
